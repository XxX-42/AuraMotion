# 320 vs 640 paired iris benchmark

In the Debug app, open **视线校准**, then select **320/640 虹膜基准**. Keep the head still and look at each yellow dot until it advances. The benchmark waits for at least six valid paired frames per target and uses the same nine positions as the existing calibration. Closing the window cancels it and returns the face worker to ordinary 320 mode. It does not alter the gaze calibration, region resolver, gesture or cursor control.

Each camera frame is rendered once at up to 640 pixels along its longest side; one VIDEO-mode MediaPipe instance receives a 320 downsample and a separate instance receives the 640 image. Results must have identical frame ID and host time; incomplete pairs are counted but excluded from all comparisons. A source whose actual longest side is less than 640 is rejected, not called a 640 measurement. The paired run deliberately executes both inferences, so its FPS is not either model's standalone FPS. Reported per-model milliseconds measure the MediaPipe inference calls; paired FPS also includes camera delivery, both models, conversion, transport and dropped frames.

For both resolutions the report records raw left/right iris x/y, z separately, the existing per-eye normalized x/y features, host timestamps, frame IDs, mirror and timestamp-quality flags, and head pose. It reports (1) pooled within-target RMS in 4D feature space, (2) the smallest 4D distance between two target centroids, (3) their ratio, and (4) nearest-centroid 9-class accuracy with first-half/second-half time-split validation in both directions. Chance is approximately 1/9 when target classes are balanced. These are descriptive measurements, not guaranteed eye-tracking accuracy; target observations come from a single continuous pass, and time-split frames are highly correlated. Head motion, blinks, drift, target order, missing detections and tracker state can bias the results. The overall yaw/pitch/roll range helps audit whether the head was stable, but does not correct for head movement. Repeat independent sessions and vary target order before drawing a strong conclusion.

On completion the report and all numeric observations are saved as JSON under `build/iris-benchmarks/`; no camera images or video are saved. The per-target sequence may wait indefinitely when either resolution lacks valid eye features. Green face landmarks or a successful run alone do not establish separability. No gaze regression is applied or trained by this benchmark.
