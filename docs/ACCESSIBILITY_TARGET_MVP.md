# Debug semantic targeting experiment

`AX Target · ON` enables this experiment for the current app session; it is off on startup. Start `GazeEstimation · Mac`, complete `CNN 角度九点校准`, close that window, and enable `手势点击与菜单` to use the existing hand pinch detector. Accessibility permission must already be granted in the existing application permission flow. The experiment does not request an extra permission. In semantic mode a confirmed pinch performs a reported `AXPress` only for a fresh locked supported target; it does not fall back to a mouse click. Disable the AX toggle to return to the existing pointer mode. CNN angular calibration coefficients are saved locally and reused after restart only when the CNN/processing signature, camera and format, input mirroring, display identity/bounds, and assumed physical geometry match; no camera images or calibration samples are saved.

The resolver uses the smoothed CNN gaze point for 13 bounded screen point hit-tests, then requires the same candidate identity to persist for 125 ms before it becomes actionable. Queries run on a serial queue, with at most one parent lookup for nested label hits. Yellow indicates a candidate and cyan indicates a confirmed focus or locked target. On a brief missing observation, the yellow candidate may remain visible for up to 800 ms, but it is not actionable until reconfirmed. It does not enumerate the AX tree. It uses the existing main-display Quartz coordinate convention; multi-display support is not implemented. AuraMotion's interactive windows are excluded, and resolving is suspended while the fullscreen calibration window is open. The cyan overlay is noninteractive. Controls that do not expose AXPress can be highlighted but will not be activated. Background or unavailable AX targets are not activated by cursor-event fallback.

Do not interpret a fitted CNN screen point as accurate gaze. Frame, title, role, distance, score, state and AXPress result appear in the HUD. The model, camera, physical screen dimensions and calibration limit target quality. A 10–20 trial comparison and accuracy, false-target and no-target counts require a human to choose known targets and record outcomes. The existing pointer path is hand-driven; an Eye→Cursor A/B mode was not previously implemented and is not invented by this MVP.

When a yellow candidate or its short visual retention is displayed, the cyan gaze marker is drawn at that target’s center. This is visual snapping only: AX discovery, scoring, and actions continue to use the original smoothed gaze and confirmed target. When the yellow candidate disappears, the marker returns to the unsnapped gaze point; it hides when gaze is unavailable and there is no retained candidate, during calibration, or when the CNN is switched off.
