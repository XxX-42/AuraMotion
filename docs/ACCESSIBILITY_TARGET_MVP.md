# Debug semantic targeting experiment

`AX Target · ON` enables this experiment for the current app session; it is off on startup. Start `GazeEstimation · Mac`, complete `CNN 角度九点校准`, close that window, and enable `手势点击与菜单` to use the existing hand pinch detector. Accessibility permission must already be granted in the existing application permission flow. The experiment does not request an extra permission. In semantic mode a confirmed pinch performs a reported `AXPress` only for a fresh locked supported target; it does not fall back to a mouse click. Disable the AX toggle to return to the existing pointer mode. CNN calibration is in-memory and must be repeated after app restart.

The resolver uses the existing fixation detector and 13 bounded screen point hit-tests on a serial queue, followed by at most one parent lookup for nested label hits. It does not enumerate the AX tree. It uses the existing main-display Quartz coordinate convention; multi-display support is not implemented. AuraMotion's interactive windows are excluded, and resolving is suspended while the fullscreen calibration window is open. The cyan overlay is noninteractive. Controls that do not expose AXPress can be highlighted but will not be activated. Background or unavailable AX targets are not activated by cursor-event fallback.

Do not interpret a fitted CNN screen point as accurate gaze. Frame, title, role, distance, score, state and AXPress result appear in the HUD. The model, camera, physical screen dimensions and calibration limit target quality. A 10–20 trial comparison and accuracy, false-target and no-target counts require a human to choose known targets and record outcomes. The existing pointer path is hand-driven; an Eye→Cursor A/B mode was not previously implemented and is not invented by this MVP.
