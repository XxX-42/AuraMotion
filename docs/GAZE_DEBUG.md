# Gaze and fixation (Debug)

The debug HUD's **视线校准** button opens a nine-target calibration on the main display. Press **开始九点校准**, then look at each yellow target and keep your head steady. Each target has a settling interval followed by multiple valid eye samples. The sequence waits if both eyes are not detected. When it completes, click a gray target to move the yellow reference dot; the cyan × shows the continuously predicted point. Closing the window keeps the model for the current app session; restart or repeat calibration to clear it. Switching the main display or the camera-data mirroring invalidates the mapping. This is a prototype and has not been accuracy-validated on the user.

The debug-only UI consumes timestamped `FaceSample` values. `EyeFeatureExtractor` uses normalized iris position within each eye and the MediaPipe yaw, pitch, roll and face scale. Closed or degenerate eyes and missing data are rejected. `GazeCalibration` learns a regularized linear mapping from all eight features to normalized screen coordinates using the nine targets. `GazeEstimator` emits a continuous Quartz screen point and the original capture timestamp. Direction is nil because no calibrated 3D optical axis is available; confidence is a heuristic input-quality score, not a detection probability. The fitted head-feature coefficients only compensate head motion represented in the calibration data and cannot be assumed to generalize to large movements.

`FixationDetector` consumes the continuous estimate with a 125 ms entry dwell, separate entry and exit radii, and quality, timing and interruption gates. It emits unavailable, candidate or focused, and never resolves a region or sends pointer events. The HUD shows the fixation state after calibration. No gaze value moves the mouse. Calibration currently lives in memory only; camera changes, display changes, imperfect eye visibility, glasses, or head motion may require recalibration. No particular accuracy is guaranteed.

The design uses general ideas described by [apayne185/cv2-eye-tracking-system](https://github.com/apayne185/cv2-eye-tracking-system) and [Joydrip/Eye-Gaze-Head-Pose-Intent-Tracker-For-Webcam-or-Phone-Camera](https://github.com/Joydrip/Eye-Gaze-Head-Pose-Intent-Tracker-For-Webcam-or-Phone-Camera); no third-party source code is copied. The suggested Aabh561/Ocula repository could not be verified, so the dwell and hysteresis implementation is independent.
