# Face samples and capture time

In Debug builds the capture pipeline sends the same immutable `SampleCarrier` to the hand mailbox and the independent face worker. The capture queue assigns a process-local, monotonically increasing frame ID. Its `hostPresentationTime` is already converted to the same host clock used by `HandSample.hostTimestamp`; `isEstimatedTime` identifies fallback timing. The face IPC sends frame ID and the exact double-precision host time in a big-endian binary header, and the worker echoes both. Responses with mismatched IDs or timestamps, malformed landmarks, or malformed matrices are rejected. No face publishes an empty result rather than reusing old landmarks.

The Python worker's separate monotonic millisecond timestamp is only for the MediaPipe VIDEO API's ordering requirement. Never use it as an Eye/Hand fusion timestamp. `FaceInferenceWorker.latestSample` is a thread-safe snapshot; consumers must still check age and time difference against `HandSample.hostTimestamp`, consider estimated timestamps, and handle missing/stale samples. No synchronization policy or eye/hand fusion is implemented yet.

`FaceSample` retains all MediaPipe x/y/z landmarks in video-data image coordinates (x right, y down); `isMirrored` records the source connection state. Iris centers use MediaPipe's subject-relative indices 473 (left) and 468 (right), and are optional when absent. The 4×4 matrix is MediaPipe's canonical-face-to-detected-face transform: its JSON rows are converted to SIMD columns; it is not a calibrated camera extrinsic. `HeadPose` uses radians and the `Rz(roll) * Ry(yaw) * Rx(pitch)` Euler convention; its center and scale come from the 2D landmark bounding box in normalized image coordinates. These angles are derived estimates, not calibrated physical measurements. MediaPipe's Face Landmarker does not expose an overall face confidence score, so confidence is nil rather than an invented value.

The HUD consumes the same typed sample, but notifications are only presentation updates, not the time synchronization mechanism. Debug face inference remains optional and requires `scripts/setup_mediapipe_face.sh`; release builds do not launch the Python worker.
